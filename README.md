# เพื่อนยามรถเสีย กทม. 🚗

เว็บแอปช่วยคนที่รถเสียใน **กรุงเทพฯ** รวม **รถสไลด์ · รถลาก · อู่ซ่อมรถ** ไว้ที่เดียว
เลือกเจ้าที่ใกล้ที่สุด แล้ว **จองคิวได้ใน 3 ขั้นตอน**

- HTML / CSS / JavaScript ล้วน **ไม่ต้อง build** และ **ไม่มี backend**
- `index.html` อยู่ที่ root ทุกไฟล์อ้างอิงด้วย **พาธแบบ relative** จึงวางบน GitHub Pages ได้ทันที
- ออกแบบให้ใช้บนมือถือก่อน ปุ่มน้อย ตัวใหญ่ กดง่าย และมีโหมดมืดอัตโนมัติสำหรับตอนกลางคืน
- แอนิเมชันด้วย [anime.js](https://animejs.com/) v4 ที่เล่าเรื่อง "รถสไลด์มารับรถ" และ "บัตรคิว" แต่ทั้งเว็บยังเบามาก (~80 KB แบบ gzip รวมฟอนต์)

> ⚠️ **เวอร์ชันสาธิต** รายชื่อร้านทั้งหมดเป็น **ข้อมูลตัวอย่าง** และบัตรคิวบันทึกไว้ในเครื่องของผู้ใช้เท่านั้น (ยังไม่ส่งถึงร้านจริง)
> ส่วน **เบอร์ฉุกเฉินเป็นเบอร์จริง** ของหน่วยงาน

---

## ใช้งานยังไง (3 ขั้นตอน)

1. **เลือกบริการ** — รถสไลด์ / รถลาก / อู่ซ่อมรถ (ถ้าไม่แน่ใจ กด "ไม่แน่ใจว่าควรเรียกแบบไหน?" มีคำแนะนำสั้น ๆ)
2. **เลือกร้านใกล้คุณ** — กด "ใช้ตำแหน่งปัจจุบัน" หรือเลือกเขต ร้านที่ใกล้ที่สุดจะขึ้นก่อน พร้อมระยะทาง เวลามาถึงโดยประมาณ ราคาเริ่มต้น และเวลาเปิด-ปิด
3. **ยืนยันจองคิว** — บอกจุดที่รถอยู่ อาการ ชื่อ และเบอร์โทร แล้วกดยืนยัน จะได้ **บัตรคิว** (เช่น `S-012`) พร้อมรหัสจอง
   กด "แชร์รายละเอียด + ตำแหน่ง" เพื่อส่งทาง LINE/SMS ให้ร้านหรือคนที่บ้านได้ทันที (มีลิงก์ Google Maps ของจุดที่รถอยู่)

ปุ่ม **โทรฉุกเฉิน** สีแดงอยู่มุมขวาบนทุกหน้า: 1669 (เจ็บป่วยฉุกเฉิน) · 191 (ตำรวจ) · 1543 (ทางด่วน) · 1193 (ทางหลวง) · 1137 (จส.100) · 1644 (สวพ. FM91) พร้อมเช็กลิสต์ความปลอดภัยตอนรถเสีย

## แอนิเมชันด้วย anime.js (เล่นครั้งเดียวแล้วหยุด เพื่อประหยัดแบต)

| ที่ไหน | แอนิเมชัน |
|---|---|
| หน้าแรก | รถที่เสียเปิดไฟฉุกเฉินกะพริบ ควันลอยจากฝากระโปรง → รถสไลด์ถอยเข้ามา (ล้อหมุนถอยหลังตามระยะจริง) → กระบะเอียงลงแตะพื้น → สลิงกว้านรถขึ้นกระบะ → กระบะกลับแนวราบ → ขึ้นเครื่องหมายถูก (แตะภาพเพื่อดูซ้ำ) |
| หาตำแหน่ง GPS | วงเรดาร์กระจายรอบหมุด แล้วหมุดเด้งลงเมื่อเจอตำแหน่ง |
| รายชื่อร้าน / คิวของฉัน | การ์ดไหลขึ้นทีละใบ |
| ฟอร์ม | ช่องที่ยังไม่กรอกสั่นเตือน, ตัวเลือกเด้งเมื่อแตะ |
| ปุ่ม "ยืนยันจองคิว" | รถสไลด์คันเล็กวิ่งผ่านปุ่มบนถนนเส้นประ |
| บัตรคิว | วงกลมถูกวาดเครื่องหมายสำเร็จ → บัตรคิวค่อย ๆ ออกจากช่องเหมือนเครื่องกดบัตรคิว → เลขคิววิ่งขึ้น → วาดเส้นทาง แล้วรถวิ่งตามเส้นมาถึงหมุดของคุณ |
| ยกเลิกคิว | ตรายาง "ยกเลิกแล้ว" กระแทกลงบนบัตร |

- ถ้าผู้ใช้ตั้งค่า **ลดการเคลื่อนไหว** (reduce motion) หรือโหลด anime.js ไม่ได้ เว็บจะแสดงภาพนิ่งและใช้งานได้ครบทุกอย่าง
- ขยับเฉพาะ `transform` / `opacity` และ SVG ขนาดเล็ก จึงลื่นบนมือถือราคาประหยัด

## เบาแค่ไหน

ขนาดแบบ gzip (ที่ GitHub Pages ส่งจริง) ของทุกไฟล์ที่ต้องโหลดตอนเปิดหน้าแรก

| ไฟล์ | ขนาด |
|---|---|
| `index.html` (รวมไอคอน SVG และภาพหน้าแรก) | 5.9 KB |
| `assets/css/style.css` | 7.2 KB |
| `assets/js/*.js` (data, core, fx, app) | 25.0 KB |
| `assets/vendor/anime.slim.min.js` | 16.3 KB |
| ฟอนต์ Prompt 2 น้ำหนัก (ตัดเหลือไทย+อังกฤษ) | 25.2 KB |
| **รวม** | **~80 KB** |

ไม่มีรูปภาพ (ใช้ SVG ทั้งหมด) · สคริปต์ใช้ `defer` ไม่บล็อกการแสดงผล · หน้าแรกเป็น HTML นิ่งที่เห็นได้ทันทีก่อน JavaScript ทำงาน

## เผยแพร่ด้วย GitHub Pages

1. push โค้ดขึ้น GitHub (มีอยู่แล้วใน repo นี้)
2. ไปที่ **Settings → Pages**
3. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
4. Branch เลือก branch ที่มีโค้ดนี้ (เช่น `main`) และโฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
   สำหรับ repo นี้คือ `https://boom-vitt.github.io/aichuaythai-boombignose/`

ไม่ต้องตั้งค่าอะไรเพิ่ม เพราะทุกพาธเป็นแบบ relative จึงทำงานได้ทั้งในโฟลเดอร์ย่อยของ GitHub Pages และโดเมนของตัวเอง
(GitHub Pages เป็น HTTPS อยู่แล้ว ปุ่ม "ใช้ตำแหน่งปัจจุบัน" จึงใช้ GPS ได้)

- หรือเปิดเซิร์ฟเวอร์เล็ก ๆ เพื่อให้เหมือนของจริงที่สุด:


## แก้ข้อมูลร้าน / ใช้งานจริง

แก้ที่ไฟล์ `assets/js/data.js` ไฟล์เดียว

```js
{ id: 'sl-bangna', type: 'slide', name: 'ชื่อร้าน', district: 'บางนา', area: 'ถนน/จุดสังเกต',
  lat: 13.6680, lng: 100.6045, rating: 4.8, reviews: 212, hours: '24h',
  price: { base: 1200, incKm: 10, perKm: 30 }, tags: ['รถ EV'],
  phone: '0812345678' }   // ใส่เบอร์แล้ว จะมีปุ่มโทร และปุ่มส่ง SMS รายละเอียดการจองถึงร้าน
```

- `type`: `slide` รถสไลด์ · `tow` รถลาก · `garage` อู่ซ่อมรถ (`mobile: true` = มีช่างออกไปซ่อมนอกสถานที่)
- `hours`: `'24h'` หรือ `{ open: '08:00', close: '18:00', closed: [0] }` (0 = วันอาทิตย์)
- `district` ต้องเป็นชื่อเขตที่อยู่ในรายการ `districts`
- ใส่ร้านจริงครบแล้ว เปลี่ยน `sample: true` เป็น `false` ป้าย "ข้อมูลตัวอย่าง" จะหายไป

เว็บนี้ไม่มี backend การจองจึงไปถึงร้านผ่านการ **โทร / SMS / แชร์ LINE** จากเครื่องผู้ใช้
ถ้าต้องการให้ร้านเห็นคิวในระบบกลาง ค่อยต่อ backend (เช่น Google Sheets หรือ Supabase) เพิ่มทีหลังได้

## เกี่ยวกับไฟล์ anime.js

`assets/vendor/anime.slim.min.js` คือ anime.js **v4.5.0** ที่รวมเฉพาะฟังก์ชันที่เว็บใช้
(`animate`, `createTimeline`, `stagger`, `utils.set/remove`, `svg.createDrawable/createMotionPath`)
ขนาด 16 KB (gzip) จากตัวเต็ม 41 KB ใช้งานผ่าน `window.anime` ชื่อเดียวกับไฟล์ทางการ

ถ้าอยากใช้ความสามารถอื่นของ anime.js ให้เปลี่ยนไปใช้ไฟล์เต็ม `anime.umd.min.js` จาก npm/CDN
หรือสร้างไฟล์ slim ใหม่ (ทำครั้งเดียว ตัวเว็บยังไม่ต้อง build):

```bash
npm i animejs@4.5.0 esbuild
cat > slim-entry.js <<'EOF'
export { animate } from 'animejs/animation';
export { createTimeline } from 'animejs/timeline';
import { stagger, set, remove } from 'animejs/utils';
import { createDrawable, createMotionPath } from 'animejs/svg';
export { stagger };
export const utils = { set, remove };
export const svg = { createDrawable, createMotionPath };
EOF
npx esbuild slim-entry.js --bundle --minify --format=iife --global-name=anime --outfile=anime.slim.min.js
```
