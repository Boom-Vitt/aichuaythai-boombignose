# เพื่อนยามรถเสีย กทม. 📞

สมุดเบอร์โทรสำหรับคนที่รถเสียใน **กรุงเทพฯ** — ขั้นแรกบอกตำแหน่งด้วย GPS แล้วแตะแถวไหนก็โทรออกได้ทันที ไม่ต้องกรอกอะไร ไม่มีจองคิว

- HTML / CSS / JavaScript ล้วน **ไม่ต้อง build** · **ไม่มี backend** · ไม่เก็บข้อมูลผู้ใช้
- `index.html` อยู่ที่ root ทุกไฟล์อ้างอิงด้วย **พาธแบบ relative** จึงวางบน GitHub Pages ได้ทันที
- ออกแบบสำหรับมือถือก่อน ปุ่มโทรใหญ่ มีช่องค้นหาและปุ่มหมวด มีโหมดมืดอัตโนมัติ
- แอนิเมชันด้วย [anime.js](https://animejs.com/) v4 แต่ทั้งเว็บเบามาก (~65 KB แบบ gzip รวมฟอนต์)
- หลังเปิดครั้งแรก เปิดซ้ำได้แม้สัญญาณเน็ตไม่ดี (service worker)

## ขั้นแรก: รถเสียอยู่ตรงไหน?

การ์ดแรกของหน้าเว็บถามตำแหน่งก่อน

1. กด **หาตำแหน่งด้วย GPS** (หรือ **เลือกเขตเอง** จาก 50 เขตของกรุงเทพฯ ถ้าไม่อยากเปิด GPS)
2. เว็บบอกว่าอยู่แถวเขตไหน พร้อมพิกัด แล้วมีปุ่ม
   - **แชร์ตำแหน่งให้คนมาช่วย** — ส่งลิงก์ปักหมุด Google Maps ทาง LINE/SMS ให้ประกัน รถสไลด์ หรือคนที่บ้าน (ใช้ได้เมื่อมีพิกัด GPS)
   - **ค้นหาใกล้คุณใน Google Maps** — รถสไลด์ · อู่ซ่อมรถ · ร้านยาง · ปั๊มน้ำมัน รอบจุดที่รถอยู่ (เปิดแท็บใหม่ เห็นเบอร์และรีวิวล่าสุดของร้านจริง)
3. ถ้าเคยอนุญาต GPS ไว้แล้ว เว็บหาตำแหน่งให้เองตอนเปิดหน้า ไม่ต้องกด
4. อยู่นอกกรุงเทพฯ ก็ยังใช้ได้ เว็บจะเตือนว่ารายชื่อร้านเน้นกรุงเทพฯ ส่วนเบอร์ฉุกเฉิน ประกัน และยี่ห้อรถใช้ได้ทั่วประเทศ

ปุ่ม **ฉุกเฉิน** สีแดงมุมขวาบนพาไปเบอร์ 1669 / 191 ได้ทันทีโดยไม่ต้องบอกตำแหน่งก่อน
ตำแหน่งไม่ถูกส่งไปที่ไหน จำไว้แค่ในแท็บที่เปิดอยู่ (ปิดแท็บแล้วลืม)

## เบอร์มาจากไหน และตรวจสอบยังไง

- ทุกเบอร์ใน `assets/js/data.js` มีช่อง `src` เป็นลิงก์หน้าเว็บทางการของหน่วยงาน/บริษัทนั้นที่แสดงเบอร์
- ตรวจเมื่อ **28 ก.ย. 2569** ด้วยการค้นหาที่จำกัดเฉพาะโดเมนทางการของแต่ละแห่ง
  (สภาพแวดล้อมที่ใช้สร้างเว็บนี้เปิดหน้าเว็บเหล่านั้นโดยตรงไม่ได้ เบอร์ที่เจอจากการค้นหาแค่ครั้งเดียวจะค้นยืนยันซ้ำก่อนใส่)
- **ก่อนเผยแพร่จริง ควรกดลิงก์ `src` ดูอีกครั้ง หรือลองโทรทุกเบอร์** โดยเฉพาะเบอร์เอกชน
- สิ่งที่ตั้งใจ **ไม่ใส่**:
  - บริษัทประกันที่ถูกเพิกถอนใบอนุญาตแล้ว (อาคเนย์ประกันภัย, เดอะวัน, ไทยประกันภัย, เอเชียประกันภัย 1950)
  - สินมั่นคงประกันภัย เพราะยังไม่ได้ยืนยันสถานะบริษัท
  - BMW เพราะค้นซ้ำแล้วไม่พบเบอร์บนเว็บทางการ
  - ข้อความว่าการทางพิเศษฯ ยกรถฟรี เพราะไม่พบข้อความทางการ
- หลายเบอร์ของประกันและยี่ห้อรถให้บริการฟรี **ตามเงื่อนไข** เช่น ประเภทกรมธรรม์ หรือรถที่ยังอยู่ในระยะรับประกัน

## แอนิเมชันด้วย anime.js (เล่นครั้งเดียวแล้วหยุด เพื่อประหยัดแบต)

| ที่ไหน | แอนิเมชัน |
|---|---|
| ภาพหัวเว็บ | รถที่เสียเปิดไฟฉุกเฉินกะพริบ ควันลอยจากฝากระโปรง → รถสไลด์ถอยเข้ามา (ล้อหมุนถอยหลังตามระยะจริง) → กระบะเอียงลง → สลิงกว้านรถขึ้นกระบะ → ขึ้นเครื่องหมายถูก (แตะภาพเพื่อดูซ้ำ) |
| ตอนเปิดหน้า | หมุดตำแหน่งเด้งชวนกด และเบอร์ชุดแรกค่อย ๆ ไหลขึ้น |
| กำลังหาตำแหน่ง GPS | วงเรดาร์กระจายรอบหมุด แล้วหมุดหล่นลงมาปักเมื่อเจอตำแหน่ง |
| แตะเพื่อโทร | หูโทรศัพท์สั่นเหมือนกำลังเรียกสาย พร้อมคลื่นวงกลมกระจายออก |
| กดปุ่มหมวด | เลื่อนไปหมวดนั้น แล้วไอคอนหมวดเด้งบอกว่ามาถึงแล้ว |
| ค้นหา | แถวที่ตรงคำค้นค่อย ๆ ปรากฏ |

ถ้าผู้ใช้ตั้งค่า **ลดการเคลื่อนไหว** หรือโหลด anime.js ไม่ได้ เว็บจะแสดงภาพนิ่งและใช้งานได้ครบ

## เผยแพร่ด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repo
2. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch**
3. Branch เลือก branch ที่มีโค้ดนี้ และโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
   สำหรับ repo นี้คือ `https://boom-vitt.github.io/aichuaythai-boombignose/`

ทุกพาธเป็นแบบ relative จึงทำงานได้ทั้งในโฟลเดอร์ย่อยของ GitHub Pages และโดเมนของตัวเอง

## ดูบนเครื่องตัวเอง

- ดับเบิลคลิก `index.html` ก็ใช้งานได้ (แต่เบราว์เซอร์จะไม่โหลดฟอนต์จากไฟล์ในเครื่อง จึงใช้ฟอนต์ไทยของเครื่องแทน)
- หรือเปิดเซิร์ฟเวอร์เล็ก ๆ ให้เหมือนของจริง:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## แก้ / เพิ่มเบอร์

แก้ที่ `assets/js/data.js` ไฟล์เดียว เพิ่มแถวในหมวดที่ต้องการ

```js
{ num: '02-123-4567', name: 'ชื่อที่แสดง', desc: 'ใช้ทำอะไร · เวลาทำการ',
  tags: ['ชื่ออังกฤษ', 'คำค้นอื่น'], src: 'https://เว็บทางการที่แสดงเบอร์นี้' }
```

- `num` รองรับเบอร์สั้น (1669), 1800/1401-xxx-xxx, เบอร์บ้าน และมือถือ ปุ่มโทรจะตัดขีดออกให้เอง
- เพิ่มหมวดใหม่ได้ด้วย `{ id, title, short, sub, icon, items: [...] }` ไอคอนที่มีให้ใช้ดูได้ใน `index.html` (`i-alert`, `i-road`, `i-truck`, `i-shield`, `i-car`, `i-wrench`)
- ปุ่ม "ค้นหาใกล้คุณ" แก้ได้ที่ `nearby` เช่น `{ q: 'ร้านแบตเตอรี่รถยนต์', label: 'แบตเตอรี่' }`
- แก้เสร็จแล้วรัน `node --test tests/core.test.js` เพื่อตรวจรูปแบบเบอร์ เบอร์ซ้ำ และลิงก์แหล่งที่มา
- อย่าลืมเปลี่ยน `checked` เป็นวันที่ตรวจสอบล่าสุด

## เกี่ยวกับไฟล์ anime.js

`assets/vendor/anime.slim.min.js` คือ anime.js **v4.5.0** ที่รวมเฉพาะฟังก์ชันที่เว็บใช้
(`animate`, `createTimeline`, `stagger`, `utils.set`, `svg.createDrawable`)
ขนาด 16 KB (gzip) จากตัวเต็ม 41 KB ใช้งานผ่าน `window.anime` ชื่อเดียวกับไฟล์ทางการ

ถ้าอยากใช้ความสามารถอื่นของ anime.js ให้เปลี่ยนไปใช้ไฟล์เต็ม `anime.umd.min.js` จาก npm/CDN
หรือสร้างไฟล์ slim ใหม่ (ทำครั้งเดียว ตัวเว็บยังไม่ต้อง build):

```bash
npm i animejs@4.5.0 esbuild
cat > slim-entry.js <<'EOF'
export { animate } from 'animejs/animation';
export { createTimeline } from 'animejs/timeline';
import { stagger, set } from 'animejs/utils';
import { createDrawable } from 'animejs/svg';
export { stagger };
export const utils = { set };
export const svg = { createDrawable };
EOF
npx esbuild slim-entry.js --bundle --minify --format=iife --global-name=anime --outfile=anime.slim.min.js
```
